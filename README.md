# Heart Disease Prediction Using Machine Learning

This project is a supervised machine learning application developed to predict the presence of heart disease based on patient clinical information.

The project compares four classification models:

- Artificial Neural Network (ANN)
- Support Vector Machine (SVM)
- Random Forest
- XGBoost

A Streamlit-based prototype is provided for interacting with the trained models and viewing prediction results.

## Main Features

- Single-patient heart disease prediction
- Batch prediction using CSV or Excel files
- Prediction history and reporting
- Search and filter prediction records
- Excel report export
- Model performance comparison
- Confusion matrices and ROC curves
- Feature importance analysis
- Model evaluation results
